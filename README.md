# Roteiros de Estudo

Trabalho A2 de Desenvolvimento Web (DWCO8A) — site para alunos do 6º ao 9º ano encontrarem roteiros de estudo e para professores pedirem roteiros novos.

Feito por Julia Romanetto dos Santos e Pedro Henrique Vogt Verolla.

## Como rodar

```bash
npm install
npm run dev
```

Build estático (gera a pasta `out/`):

```bash
npm run build
npx serve out
```

O relatório de execução está em `relatorio.pdf`.
